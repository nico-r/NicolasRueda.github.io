Transparent Raffle Tool

Most Instagram raffles are unintentionally unfair — the most popular raffle apps only process the first 100 comments. When a post I ran for my own business, Cookies NY!, passed 250 comments, I built my own tool to fix it: a web app that extracts every comment (via HTML parsing with Python/BeautifulSoup, bypassing the 100-comment cap), validates entries against custom rules (mandatory friend tag, one entry per person), and runs a fair, auditable draw using a Fisher-Yates shuffle — generating a downloadable proof of randomness. Used for a real giveaway with 180+ comments. .
